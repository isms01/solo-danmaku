# solo-danmaku（一人ニコニコ動画）

手元の動画に、AIが生成した「観客」を召喚する。

弾幕は本来、群衆がいて初めて成立する。
自分で撮った動画に群衆はいない。ならば作る、というツール。

![demo](docs/demo.gif)

> **Status**: prototype (v0.1) / 単一HTMLファイル、ビルド不要

## 仕組み

```
動画 → フレーム抽出 → Claude (vision) → タイムスタンプ付きJSON → 再生同期で弾幕描画
```

生成と再生を**分離**しているのが設計の中心。
モデルは描画を一切行わず、バリデーション済みの `{ t, text, size }` 配列を返すだけで、
描画は決定的なレンダラが担当する。

この構成から2つの性質が得られる。

- **再生が決定的** — 同じコメントデータなら何度でも同一の再生結果になる。
  プロンプトを変更した際、固定のベースラインと比較できる
- **シークが効く** — コメントはストリームではなくタイムスタンプで引くため、
  巻き戻し・早送りに追随する

モデルが壊れた出力を返しても、不正な要素が破棄されるだけで描画は継続する。

却下した設計案を含む詳細は [docs/SPEC.md](docs/SPEC.md) を参照。

## 使い方

`index.html` をブラウザで開く。動画ファイルを選んで生成、あとは再生するだけ。

動画本体は端末外に出ない。APIに送るのは縮小したフレーム画像のみ。
